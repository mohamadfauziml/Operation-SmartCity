LEARNING OUTCOMES

Your Engineering Objectives

By completing the SmartCity mission journey, you will be able to:

Understand IoT Components

Explain the purpose of sensors, connectivity, processing units, cloud platforms, actuators, and user interfaces.

Connect the System

Describe how IoT components work together to collect, transmit, process, and act on data.

Investigate Deployments

Analyse real-world IoT systems and identify the components used in each deployment.

Design a Solution

Create a simple IoT solution using components appropriate to the problem and its engineering constraints.

TEACHING GUIDE

For Lecturers

This portal supports a four-stage learning progression: Understand → Apply → Analyse → Design. The four games are independent and can be used individually. For a complete learning journey, students should complete them in the recommended order.

Suggested classroom use

  • Mission 1: Establish component knowledge
  • Mission 2: Develop system interaction understanding
  • Mission 3: Practise system analysis
  • Mission 4: Demonstrate solution design

Student scores and responses remain inside each individual game and are not transferred to this portal.
